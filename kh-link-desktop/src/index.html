    仅存本机
    这些额度数字从哪里来？

    读取官方 Claude Desktop 已保存的用量响应与历史记录，或 Claude Code 官方状态栏交出的数据。这里的“更新记录”只重新读取本机，不向 Claude 发送消息或查询请求。

    未使用的账号到达已记录的重置时间后，显示“预计剩余 100% · 待官方确认”，保留原数据时间。若在其他设备使用，实际额度可能更少；切回后以新官方记录为准，不推算下一次重置时间。

    其余记录超过 30 分钟、或当前账号已到重置时间，会标为历史数据。没有官方记录或重置时间时不预测，显示“暂无记录”或“官方记录未提供”。

    仅存本机
    登录、切换与额度说明

    添加账号后会打开一个空的官方 Codex 窗口，请在其中完成登录。下次点击“切到窗口”或“打开账号”即可继续使用；旧窗口保持运行，需要时可自行退出。

    额度由官方 Codex 账号接口返回。只更新最近从这里打开的账号，其他账号保留上次读取时间；没有数据时显示“暂无记录”，超过 30 分钟或重置时间后显示历史值。登录后可点击“更新用量”。

    khLink 不读取、复制或输出登录文件，不发送模型消息。账号数据保存在 G 盘；本页的备注名称仅用于你自己辨认。

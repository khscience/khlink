# KH Link 二维码直连

电脑显示连接码，手机扫一次就连上，不需要 khLink 账号和服务器。手机自动回传加密的握手，电脑不用扫手机，也不用点确认。消息、审批、文件和历史读取都走两端之间的加密通道，复用现有连接器和 Agent 进程。

- **同一 Wi-Fi／手机热点**：点对点 WebRTC 直连，不需要任何外部服务。不勾选「手机和电脑不在同一 Wi-Fi／热点」。
- **跨网络**（手机用流量、或在别的 Wi-Fi）：勾选上面那项后再生成连接码。电脑经 Cloudflare 临时通道（quick tunnel）接收手机的连接；cloudflared 已打进安装包，不需要 Cloudflare 账号。内容用配对密钥端到端加密，Cloudflare 和 khLink 服务器都看不到明文。第一帧必须能用配对密钥解开，否则断开。
- **不访问 STUN**：直连不向任何公共 STUN 服务器询问地址，电脑和手机的公网地址不会被第三方得到。
- 二维码只包含本次连接的密钥、精简后的 SDP、局域网回传地址和临时通道名，不包含云端账户主密钥、刷新令牌或 Agent 凭据。

## 使用步骤

1. 电脑打开 khLink →「二维码直连」，生成连接码。准备阶段保留原账户连接。
2. 手机在登录页扫描电脑二维码；已登录账户的，可以从头像 →「二维码直连」进入。也支持从相册导入，或粘贴配对链接。
3. 手机自动完成握手，两端显示「已直连」，电脑上的连接窗口可以关掉。
4. 电脑在手机握手通过后才切换为直连。电脑首页的「恢复账户连接」可恢复账户服务；手机用「返回账户连接」。详见[桌面流程](desktop-connection-flow.md)。

## 自动重连

扫过一次后，手机记住这台电脑：

- **App 重开、手机切到后台再回来、换 Wi-Fi 再回到同一网络**：在同一局域网里经 UDP 找到电脑（优先端口 47820），用配对密钥重新握手，不用扫码。
- **跨网络**：经原来的临时通道重连。连接器重启或更新时，cloudflared 继续运行，新连接器接上同一个通道，地址不变。
- **电脑重启**：临时通道地址会变，在外面要重新扫码；回到同一 Wi-Fi 会自动连回。
- 自动重连连续失败约 1 分钟，App 弹窗建议改用账号登录。

一台电脑同一时间只连一部手机；需要多台设备同时用，请用账号连接。

## 服务器连接待命

电脑也登录了账户时，直连期间账户连接不会断开，而是待命：只发送在线状态（服务器不计流量），历史只写在电脑本地。手机改用账号登录、通过服务器发来第一条命令后，连接器把断档期间的会话和消息从本地补传到服务器，然后恢复正常同步。只扫码、没登录账户的电脑完全不连服务器。

## 连接限制

二维码只能用一次，有效期五分钟。尚未收到手机握手时关闭对话框会取消配对；已连接时关闭对话框会保留直连。「取消配对」或「断开直连」会关闭通道。

跨网络依赖 Cloudflare 临时通道：公司或学校网络屏蔽 Cloudflare 时可能连不上，这时换用同一 Wi-Fi／热点，或改用账号连接。

手机退到后台后要保持连接，需要允许 khLink 后台运行。ColorOS 请在「应用信息 → 耗电管理」打开「允许后台行为」，否则系统可能冻结进程，使直连中断。

## 实现

- 局域网握手：手机向电脑的临时 UDP 端口发送加密答复；分片可乱序重组，丢包会重试，同一答复只处理一次，回复也经过加密认证。取消或到期后入口失效；公网入口不能调用本机控制接口。
- 临时通道：cloudflared 把一个 `*.trycloudflare.com` 地址转发到电脑 `127.0.0.1` 上的 WebSocket，路径分别是 `/khlink/<连接码 id>`（配对）和 `/khlink/resume`（重连）。通道的进程号、端口和地址记在 `%APPDATA%\FengzhuAgentBridge\direct-tunnel.json`。
- 直连历史：在电脑上按账户密钥隔离并加密存储，再用当前连接的密钥重新加密后发给手机。写入时先落盘再改名，文件损坏会自动挪开并重新同步。

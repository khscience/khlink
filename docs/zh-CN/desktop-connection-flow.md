# KH Link 桌面连接流程

桌面端 0.1.6、连接器 0.2.40 将账户和通信方式分别显示。首页始终保留账户栏，并分别显示后台是否运行、手机是否连接。

## 账户连接

1. 在首页账户栏或右上角点击“登录账户”，再点击“在浏览器中登录”。
2. 在 khsci.com 网页上登录 khLink 账号并授权，返回桌面端。授权成功后会准备账户连接；失败或五分钟超时后可以重试，也可以取消。
3. 手机登录同一 khLink 账号即可连接。首页“账户配对码”是另一种绑定手机的方法，它通过账户服务完成绑定。

直连期间仍可登录账户。打开登录窗口不会断开直连；登录成功并完成账户连接准备后，才结束直连、切换连接方式。取消网页授权不会清除原账户或切换连接。

“退出桌面账户”清除桌面管理界面的登录会话，已绑定手机的后台连接继续运行，当前直连也会保留。若桌面未登录而手机后台仍在线，首页分别显示“后台连接正常”和“未登录账户”。撤销某部手机的访问权请在已绑定设备中解除绑定。

## 二维码直连

1. 点击“二维码直连”，自动生成电脑连接码。同一 Wi-Fi／热点下保持“手机和电脑不在同一 Wi-Fi／热点”未勾选。
2. 手机 KH Link 扫描电脑连接码一次，自动回传加密握手，随后建立两端直连。电脑无需扫描手机码或点击确认。
3. 两端显示连接完成后即可使用。需要手机 ≥ 0.1.189、连接器 ≥ 0.2.40。

准备二维码时原账户连接继续运行，验证手机答复后才切换。取消配对会作废未完成的二维码；连接完成后点击“完成”或关闭窗口，直连继续运行。“断开直连”只断开当前直连，首页保留“恢复账户连接”。匿名用户可从同一位置登录并使用账户连接。

直连期间账户栏只显示本机保存的账户信息，不请求云端会员或设备列表。跨网络穿透和后台限制沿用[二维码直连说明](direct-connection.md)。

## 状态与验证

- **账户**：未登录／已登录，由桌面账户会话决定。
- **连接方式**：账户连接／二维码直连，由本机配置决定。
- **电脑后台**：运行中／未运行，由新鲜心跳决定。
- **手机直连**：已连接／未连接，由认证后的数据通道决定。

授权网络操作放在后台执行，不占用界面状态锁；回调只接收本次授权的 `/callback` 和正确 state，忽略 favicon 等无关请求。授权码只兑换一次，取消后的迟到结果不写入账户。界面忽略切换模式前发出的旧账户响应。

回归命令：

```powershell
node --test kh-link-desktop/test/flows.test.cjs
cd kh-link-desktop/src-tauri
cargo test --lib
```

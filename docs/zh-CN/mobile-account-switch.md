# 手机端账号切换

> **当前状态：** Claude 账号切换自 2026-10-18 起暂停（见 [Claude Desktop 多账号切换](claude-account-switch.md)）。手机只保留 Codex 的只读账号列表；Claude 页不显示账号按钮、额度卡或切换入口。下面记录完整设计。

## 目标

手机的 Codex、Claude 页可以查看当前账号和各账号额度，并（对 Claude）切换账号。手机和电脑上的桌面控制台看到同一份账号状态：任何一端发起切换，另一端几秒内显示进度和结果；一端在切换时，另一端的切换入口不可用。Pi 和 Antigravity 没有账号概念，不显示入口。

分两期：

- **第一期**：Claude 在手机上切换（整机切换）；Codex 只读查看列表、额度和实例状态，不提供远程打开。
- **第二期**：Codex 多账号进入手机会话体系，需要连接器支持多个 `CODEX_HOME`，单独评估。

## 设计

### 切换逻辑只有一份

完整编排在桌面控制台（Rust）里。桌面端提供无界面的命令行入口给连接器调用，和界面共用同一把锁；连接器里不复制一份编排逻辑。

### 协议

- 能力：连接器在 capabilities 里声明 `accounts.v1`。旧手机看不到入口，新手机遇到旧连接器也不显示。
- 读取：`accounts.read {backend}` 返回 `{ backend, active, switching, lastSwitch, profiles: [{ id, name, active, running, quota: { fiveHour, week, observedAt, estimated } }] }`。只给账号别名和用户自己起的显示名，不给邮箱、组织 ID、本机路径或任何令牌。
- 切换：`accounts.switch {backend: 'claude', to, requestId}` 立即返回接受或拒绝原因（含阻塞清单）；过程中推送 `accounts.progress {requestId, phase, message}`，阶段为 checking / closing / syncing / opening / done / failed，结束推送 `accounts.state`。
- 同一个 `requestId` 重放不会重复执行。连接器重启后从锁文件和账号状态恢复真实状态，不猜测。多台手机同时在线时，锁保证只有一个切换在进行，其他手机看到“另一台设备正在切换”。

### 切换前的拦截

退出 Claude Desktop 会结束其中所有本地会话进程。下面任一情况都拒绝切换，并在手机上列出原因，不提供强制切换：

- 有 Claude 会话正在运行、等待审批或提问；
- 有手机排队消息没发出，或有待生效的模型、强度设置；
- 桌面显示有后台任务在运行，或定时任务几分钟内要触发；
- 另一个桌面操作正在进行；
- 后台命令或子代理还没结束（`end_turn` 只表示一次回复结束）。依据官方会话记录里的结构化后台任务 ID 和系统来源的完成通知判断，读不完或格式不认识就拒绝。

都没有时，确认框写明“电脑上的 Claude 会关闭，并以账号 X 重新打开”，以及切换期间手机无法给 Claude 发消息。

### 失败恢复（人不在电脑前）

- 目标账号启动失败：链接仍指向原账号时，自动用原账号重新打开；链接已经切到目标时，手机提供“重新打开 Claude”和“切回原账号”。
- 切换只完成一半或链接校验失败：不启动 Claude，手机显示“上次切换未完成”和可执行的恢复操作；恢复同样要拿锁。
- 残留锁：锁文件记录发起进程、发起端和开始时间。进程已不存在并超过合理时限时，先核对链接和账号状态一致，再允许清除；不一致时只提示，不自动清除。

### 显示

- 账号入口是任务列表顶部、刷新按钮左边的一个切换图标（至少 48dp），按当前智能体页打开对应的账号面板。切换中显示进度环。
- 面板里每个账号一条：名称、当前状态和切换按钮在第一行；Claude 两个额度窗口并排，Codex 只显示官方实际提供的窗口。
- 额度口径：超过 30 分钟只显示“历史剩余”；推算的重置额度标“估算”；不同账号的额度不混用。剩余量、历史或预计标记和各自的重置时间始终可见。
- Codex 页写明手机会话列表只包含默认账号。

## 安全约束

- 不读取、不复制、不传输任何凭据；切换只改目录链接，登录由官方程序自己读取。
- 日志和发给手机、中转的数据里不出现邮箱、组织 ID、令牌片段和本机绝对路径。
- 订阅账号只限本人自用。
- 本机记录审计日志：时间、发起端、从哪个别名切到哪个别名、结果和失败原因。

## 第二期：Codex 多账号进入手机

连接器监视多个 `CODEX_HOME/sessions`，会话带上所属账号；手机新建任务时选账号，对应账号的后台 app-server 用该 `CODEX_HOME` 启动；额度按账号分别读取；发送前核对目标窗口属于该账号。

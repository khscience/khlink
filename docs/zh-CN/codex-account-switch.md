# Codex 多账号

桌面控制台的“账号切换 → Codex 切换”可以管理多个 Codex 账号：每个账号用自己的官方 Codex 窗口，可以同时开着，互不影响。手机只读显示这些账号。

## 怎样工作

- **默认账号**：继续用现有的 Codex 数据目录，不搬移、不注销、不读取登录文件。手机远程控制始终连接默认账号的 Codex。
- **其他账号**：在管理根目录（代码里是 `G:\Apps\CodexSwitch`）的 `profiles\<随机 ID>\` 下建一个空的 Codex home 和 Electron 用户目录，由用户本人在官方程序里登录。
- **切换**：启动或聚焦对应账号的官方窗口。原来的窗口和任务保留，不关闭、不强制结束 Codex，不改系统环境变量、默认快捷方式和手机连接的账号。
- 每个账号的登录、本地聊天和置顶各自独立，不跨账号复制聊天、Cookie、令牌或配置。

## 额度和登录状态

- 通过官方 `codex app-server` 的 `account/read`（`refreshToken: false`）和 `account/rateLimits/read` 读取，只取公开的账号状态和额度字段；不读 `auth.json`，不请求或输出令牌，不发模型消息。每次请求的子进程明确指定自己的 home。
- 卡片显示官方实际返回的额度、重置时间、读取时间和登录状态。官方没有返回 5 小时窗口时隐藏这一项；不知道的额度显示“暂无记录”，不显示成 100%。不查询没有选中的账号。
- 卡片在备注下显示官方返回的邮箱和套餐。邮箱只在桌面显示，不发给手机。
- 手机的默认账号额度和桌面用同一个只读接口，30 秒内的重复请求合并；账号变化会刷新当前对话，退出或没有额度时清掉旧数字，迟到的结果丢弃。

## 移除和恢复

备用账号可以从 khLink 的列表中移除，也可以恢复，见[账号移除与恢复](account-management.md)。默认账号是手机的连接入口，不能移除。

## 安全约束

- 新建的目录和元数据都限定在管理根目录内；路径要校验，写入用原子替换并加锁；遇到外部链接、目录穿越或不认识的配置就停止。
- 程序路径只取官方安装登记里的路径。新账号第一次登录始终由本人操作，工具不代点任何安全确认。
- 手机定位窗口时同时核对官方主进程和命令行，只认默认实例；带 `--user-data-dir` 的备用实例不参与手机操作。连接器必须声明新版适配器能力、并且状态在 30 秒内更新过，桌面才允许打开备用账号，避免旧连接器选错窗口。

## 依据

- 官方 [Authentication](https://learn.chatgpt.com/docs/auth)：Codex 按 `CODEX_HOME` 保存配置和本地登录状态，由官方负责登录和续期。
- 官方 [App Server](https://learn.chatgpt.com/docs/app-server)：提供公开的账号读取和额度读取接口。
- 官方 Codex 桌面应用接受 `CODEX_ELECTRON_USER_DATA_PATH` 来使用独立的 Electron 目录，单实例锁按这个目录区分，并保留 `CODEX_HOME`。

## 还没做的

手机上的 Codex 只读：会话列表只包含默认账号，不能远程打开或切换其他账号。让手机看到所有账号的会话需要连接器同时监视多个 `CODEX_HOME`，见[手机端账号切换](mobile-account-switch.md)的第二期。

# 账号移除与恢复

桌面控制台的 Claude 和 Codex 账号卡片都有“移除”。移除只是把账号从 khLink 的管理列表里拿掉：官方账号数据、登录状态和共用的对话都保留，也不会退出或关闭官方软件。被移除的账号列在单独的“已移除账号”折叠区里，可以恢复。

（Claude 账号切换目前已暂停，见 [Claude Desktop 多账号切换](claude-account-switch.md)。下面的规则对两者都适用。）

## 规则

- 当前使用的 Claude 账号不能移除，至少保留一个已登记的账号；默认 Codex 账号是手机的连接入口，也不能移除。受保护的按钮会说明原因，后端同样校验，旧界面或旧请求绕不过去。
- 移除后的账号不再接受切换、打开或刷新请求，包括迟到的手机请求。恢复不会启动官方应用，也不会自动登录。
- 移除和切换共用同一套锁：切换或恢复进行中时拒绝移除。移除非当前账号不需要退出正在运行的 Claude。只改本地登记文件，不扫描、读取、复制或删除凭据。
- 卡片上的改名和移除在同一行；确认框可以取消或按 Esc，操作期间防止重复提交和旧轮询覆盖。

## 数据

- 移除不等于注销，也不清理磁盘。Claude 的记录写进管理根目录 `shared/config.json` 的 `removedProfiles`；Codex 的写进 `accounts.json` 的 `removedProfiles`。目录、备注、用量和共享的对话数据都保持不变。
- 恢复时会再次校验保留的目录；目录被外部清理或变成不认识的链接时停止。
- 手机自动跟着桌面更新列表：连接器检查登记文件的修订号，有变化才重新读取并推送。已移除的记录和本机路径不会发给手机。

## 降级

降级到没有“移除”功能的旧版桌面端之前，先在新版里恢复足够的 Claude 账号，让活动账号至少有两个；旧版的共享脚本要求至少两个账号。不要为了降级删除目录或恢复登录文件。

## 以后可以做的

1. 共享对话和备份的健康检查：显示正文入口、目标目录是否存在、最后一次校验和备份的时间及异常原因。
2. 添加账号向导：检查目录结构和官方版本，建立空的 profile，提示由本人首次登录。
3. 账号多时增加搜索、固定排序和常用标记。

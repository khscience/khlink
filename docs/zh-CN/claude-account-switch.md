# Claude Desktop 多账号切换

> **当前状态：暂停。** 自 2026-10-18 起，Claude Desktop 账号切换在桌面控制台、连接器和手机三个入口都已关闭：桌面不显示“Claude 切换”页，连接器对 `accounts.read` / `accounts.switch` 返回关闭或拒绝，手机不显示 Claude 账号按钮和额度卡。原因是条款复核：账号切换涉及多账号轮换、官方窗口自动化和数据目录切换，风险高于只读读取。代码保留在仓库里，本文记录它的设计，供以后重新评估。

## 目标

1. 每个账号在官方 Claude Desktop 里由本人登录一次，以后一键切换，不用再登录。
2. 换账号后 Code 标签页的会话还在，能接着用。
3. 一个面板里显示每个账号的 5 小时和本周用量及重置时间。

不做：Chat 标签页的聊天记录存在各账号自己的服务器上，换账号后看不到，工具不处理。

## 合规边界

依据 Anthropic [消费者条款](https://www.anthropic.com/legal/consumer-terms)：账号和凭据不能给别人用；除非使用 API Key 或官方明确允许，不能用机器人、脚本等自动方式访问服务；不能绕过官方的系统或保护措施。

| 做 | 不做 |
|---|---|
| 正常关闭、启动官方 Claude Desktop | 读取、解密、复制 Cookie 或令牌 |
| 切换官方程序使用的数据目录 | 用脚本调用 claude.ai 的接口，包括查用量 |
| 读取官方程序主动交给扩展的数据和它本地缓存的用量 | 替用户发消息、自动登录、点击安全或信任确认 |
| 每个账号都是本人的，由本人登录 | 把账号给别人用；保存密码 |

条款没有写明“多个账号轮流用来叠加额度”算不算违规。约定是每个账号各有实际用途、都由本人付费；条款变化时按新条款复核本节。

## 设计

### 数据目录

```text
<管理根目录>\              代码里是 G:\Apps\ClaudeSwitch
  profiles\<账号名>\        每个账号一份完整的官方数据目录
  shared\
    config.json            登记、映射和已移除的账号
    code-indexes\          共用的 Code 会话索引和同步状态
    code-projects\         Code 会话正文
  usage.json               各账号的用量记录
```

官方程序的数据目录（商店版在 `%LOCALAPPDATA%\Packages\Claude_<发布者 ID>\LocalCache\Roaming\Claude`）改成 Junction，指向当前账号的 profile。第三方网关模式的 `%LOCALAPPDATA%\Claude-3p` 不碰。

### 切换流程

1. 检查 Code 标签页的运行任务、后台任务、审批、排队消息和待生效的设置；有任务或状态无法确认时拒绝切换并说明原因。
2. 让 Claude Desktop 正常退出，等进程全部结束，包括数据目录里的辅助进程（例如浏览器扩展启动的 Native Host）。不强制结束进程。
3. 同步共享的 Code 会话索引（见下）。
4. 把数据目录的 Junction 改指向目标账号。
5. 启动官方程序。

整个过程由一把操作锁覆盖。退出失败就留在原账号；Junction 替换失败就恢复原链接；不会带着同步一半的状态打开另一个账号。

添加账号：建一个空 profile，登记为“待登录”，打开官方登录窗口，由本人登录并打开 Code 页，正常退出后完成添加。工具只识别 Code 的目录名和白名单索引，不扫描登录文件；有多个候选或结构不认识时停止。

### 共用 Code 会话

官方 Code 把会话索引存在 `claude-code-sessions/<账号>/<组织>/local_<UUID>.json`，用原子替换写文件，所以不能用硬链接共享；整个目录里还有定时任务，直接共享会把定时任务带到另一个账号。因此只在正常退出之后同步选定的账号/组织下的会话索引：

- 只处理白名单里的 `local_<UUID>.json` 和可重建的 `archived-sessions.idx`，不碰登录文件、Chat、定时任务和用量文件。
- 按文件摘要传递新建、改名、归档等变化，不按修改时间覆盖；非活动 profile 有独立改动或同名不同内容时停下，作为冲突处理。
- 写入前保存本次涉及的文件并记录事务，出错先恢复本次文件；回退前同样要求退出，发现会丢掉新变化就拒绝覆盖。
- 会话正文由同一个 Windows 用户共用，通过 `~/.claude/projects`（指向 `shared\code-projects` 的 Junction）访问。
- 置顶和顺序另外同步四个白名单 UI 偏好键，以及 IndexedDB 里的置顶状态。

### 用量

- 优先使用官方 statusLine 回调主动交来的数据；也被动读取官方程序自己取得并缓存在本地的用量响应，只取四个额度字段和时间。
- 每个账号都显示观测时间；没有新观测就标为历史数据。不在用的账号不做后台查询。
- 非活动账号有官方比例、有效观测时间和晚于观测的明确重置时刻，并且已经到了该时刻，才显示“预计剩余 100% / 待官方确认”。当前账号到期仍显示待更新。
- 手机只接收当前账号的额度、各自的观测和重置时间及账号指纹；切换中、目录不明或来源无效时不显示别的账号或命令行探针的数字。所有安装都不再为查额度发送命令行探针或模型消息。

## 风险

- 官方程序更新后，数据目录结构或登录存放方式可能变化，切换会失效。每次升级后要重新核对。
- 关闭 Desktop 不等于相关辅助进程都退出；切换检查必须覆盖数据目录里的辅助进程，不强制结束浏览器，也不修改扩展权限。
- 登录过期只能在官方程序里重新登录，工具不处理。
- 手机新建的 Claude 任务和侧边栏操作会经过桌面窗口自动化；切换期间这些请求必须被拒绝并返回原因，不能投递到另一个账号。
